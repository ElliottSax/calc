## Maintenance & Updates

### Adding New Articles
1. Add entry to ARTICLES_MANIFEST in `/lib/blog/articles-manifest.ts`
2. Create directory: `/app/blog/[new-slug]/`
3. Create file: `/app/blog/[new-slug]/page.tsx`
4. Update related article links in manifest
5. No other changes needed - system handles everything else

### Updating Existing Articles
1. Edit metadata in articles-manifest.ts
2. Edit content in page.tsx
3. Update related article links
4. No rebuild required for metadata changes

### Monitoring Performance
- Track organic search traffic
- Monitor keyword rankings
- Track email signup conversions
