================================================================================
HOW IT WORKS
================================================================================

User visits /blog/1:
  - Route handler intercepts request
  - Validates ID (numeric only, must be 1-14)
  - Looks up slug from BLOG_SLUG_MAP
  - Returns HTTP 301 redirect with Location header
  - Caches redirect for 1 year
  - Browser follows redirect to new URL
  - Search engines transfer PageRank to new URL
